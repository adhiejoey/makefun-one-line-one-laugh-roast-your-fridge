A single-line roast of a fridge, written for the make.fun bounty
"One Line, One Laugh: Roast Your Fridge".

Running `node main.ts` writes one line to `entry.txt` in the output
directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The entry roasts the fridge's crisper drawer — the spot where vegetables
go in full of good intentions and quietly give up — with the twist
landing in the final words.
